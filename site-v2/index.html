All your Claude Code sessions in one window

Stanza is a desktop app around the real claude CLI. Every tab is a genuine Claude Code session. Stanza adds what a terminal window doesn't have: your projects and their past sessions, split panes, live git status, and a panel that shows what each session is doing.

What it adds to the terminal

01

Projects, with their history.

Add a folder once. Its past sessions are listed under it, titled by what you did in them: click one to resume it, right-click to fork it and try another direction. Each project shows its branch and changed files, live.

On first launch, the three folders you used Claude Code in most recently are already there. The + in the sidebar starts a session in any of them.

02

Split the screen.

Up to four sessions side by side: drag one from the sidebar onto the terminal, or press Ctrl+Shift+→. Mix projects and shells in one split, move between panes and resize them from the keyboard.

Each split is a box in the sidebar, and its layout comes back when you reopen the app. Opening a session that's already on screen forks it, so two processes never write one transcript.

03

See what the session is doing.

The right panel follows the tab you're in: how full the context window is, which MCP servers are connected, which subagents ran with which model and prompt, the dev servers the session started (click to copy the URL), and the images it was given.

04

Make it yours.

Dark, light or the system's theme, four accents, terminal text size and interface zoom. Every shortcut can be re-recorded; the defaults stay off the keys Claude Code uses, and on a Mac they use ⌘ so Ctrl stays Claude's.

The settings here work. Pick an accent: it colors this page too.

And the rest

Tabs come back
Close the app and reopen it: your sessions resume in the same order and the same splits.
Clickable file paths
Ctrl+click src/main.js:123 in Claude's output to open VS Code at that line. Images, videos and PDFs open in their default app.
Notifications
A session in the background tells you when it needs input or has finished a longer task. Click it to jump there.
Plan limits
Session and weekly usage sit in the footer, so you see the ceiling before you hit it.
Chats without a project
For questions and small chores like tidying the Desktop. They run in Claude Chats with your home folder added.
Updates when you ask
When the repo has new commits, the footer shows what changed. Click Update: it rebuilds and reopens with your tabs.
The real claude
Slash commands, permissions and model switching are exactly what you get in a shell. Nothing is re-implemented.
Quiet when you're away
Polling pauses while the window is hidden and slows down when it isn't focused.

Install

One line. It clones the repo, builds the app and opens it. Running it again updates that copy.

You need Node.js 20 or newer, git, and the claude CLI installed and logged in.

irm https://raw.githubusercontent.com/AalishMS/Stanza/main/scripts/install.ps1 | iex curl -fsSL https://raw.githubusercontent.com/AalishMS/Stanza/main/scripts/install.sh | bash

Run it in PowerShell. It installs to %LOCALAPPDATA%\Programs\stanza with Desktop and Start menu shortcuts. Set STANZA_DIR first to pick another folder.

Run it in Terminal. It installs to ~/.stanza with a link in ~/Applications; get git with xcode-select --install. macOS isn't tested by the author, so please report what breaks.

By hand 
git clone https://github.com/AalishMS/Stanza.git
cd Stanza
npm install
npm start

To use it as a normal app, build it with npm run package and add shortcuts with npm run shortcut (Windows), or npm run package:mac for an unsigned Stanza.app.

Questions

Does Stanza replace Claude Code?
No. Every tab runs the actual claude CLI. Stanza only adds the sidebar, tabs, split panes, git status and the session panel around it.
What does it send over the network?
A git fetch of your clone to check for updates, and a request to Anthropic's usage endpoint for the plan-limit meter, using Claude Code's own login token (read, never written). Nothing else: no account, no analytics.
Will my existing sessions show up?
Yes. Stanza reads Claude Code's transcripts under ~/.claude/projects (read-only) and lists them under each project by title.
Does it work on macOS?
It's built Windows first, and every change is written with a Mac path alongside. It runs on a Mac, but the author can't test it there, so expect the odd rough edge.
Colors look off in the light theme?
Claude Code picks some of its own colors. Run /theme in a session and choose a light theme there too.
How do I uninstall it?
Delete the install folder and the shortcuts (or the ~/Applications link). Settings live in %APPDATA%\stanza or ~/Library/Application Support; remove those for a clean slate.
