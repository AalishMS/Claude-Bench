Free and open source · Windows first, macOS best effort

All your Claude Code sessions in one window.

Stanza is a quiet desktop workspace around the real claude CLI. It adds what a terminal window doesn't have: a project sidebar, split panes, live git status, and a panel for context, MCPs, subagents and running servers.

The real claude, in a real terminal

Slash commands, permissions, models and speed are exactly what you get in a shell. Nothing is re-implemented.

Free, no telemetry

MIT licensed, no account, no analytics, no silent auto-update. Your projects and settings live in one local file.

Small and quick to start

Electron, xterm.js and node-pty. No bundler, no framework. Terminal output is batched before it reaches the UI.

Quiet when you're away

Polling pauses while the window is hidden and slows down when it isn't focused. The terminal gets the space.

What it adds

The things a terminal window doesn't have.

Projects and sessions

Add a folder once. Start a session in one click.

Every project gets a list of its past sessions, titled by what you did in them. Click one to resume it, or right-click to fork it. On first launch, the three folders you used Claude Code in most recently are already there.

  • Branch, changed files and ahead/behind for every project, at a glance.
  • Folders with the same name are told apart by their parent folder.
  • Jump straight into a project, or open a chat without a project, from the quick menu.

Session details

Everything about the session, beside the session.

The right panel follows the tab you're in. See how full the context window is, which MCP servers are connected, which subagents exist and what they were asked, and what your session left running.

  • Context usage as a share of the model's window (for example 144k / 1M).
  • Subagents with their model and prompt. Click one to read its full instructions.
  • Dev servers started from the session, with their port. Click to copy the URL.
  • Images pasted into or read by the session.

Split view

Up to four sessions on screen at once.

Drag a session from the sidebar onto the terminal, or press Ctrl+Shift+→ for a new one beside the current. Keep several splits around: each gets its own box in the sidebar.

  • Mix projects, or a shell, in one split
  • Sizes and layout come back with your tabs
  • Move focus and resize panes from the keyboard
  • Opening a session twice forks it, so two processes never write one transcript

And the details

Small things that add up.

Tabs that come back

Close the app and reopen it: your sessions are resumed in the same order and the same splits.

Clickable file paths

Ctrl+click src/main.js:123 in Claude's output to open VS Code at that line. Images, videos and PDFs open in their default app.

Notifications

A background session tells you when it needs input or has finished a longer task. Click it to jump to the tab.

Plan limits

Your session and weekly usage sit in the footer ring meter, so you see the ceiling before you hit it.

Chats without a project

Pick "No project" for questions and small chores like tidying the Desktop. It runs in Claude Chats with your home folder added.

Fork a session

Right-click a past session to fork it and try another direction without touching the original transcript.

Running servers

Dev servers your session started are listed with their port. Click to copy the URL, Shift+click to open it.

Every shortcut is yours

Defaults stay clear of the keys Claude Code uses. Click any shortcut in settings to record a new one.

Shortcuts

Install

One line, then it's an app.

It clones the repo, builds the app and opens it. Running the line again updates that copy.

Windows irm https://raw.githubusercontent.com/AalishMS/Stanza/main/scripts/install.ps1 | iex
macOS curl -fsSL https://raw.githubusercontent.com/AalishMS/Stanza/main/scripts/install.sh | bash

Run it in PowerShell. Installs to %LOCALAPPDATA%\Programs\stanza with Desktop and Start menu shortcuts.

Run it in Terminal. Installs to ~/.stanza with a link in ~/Applications. Install git first with xcode-select --install.

1

You need

Node.js 20 or newer, git, and the claude CLI installed and logged in.

2

It does

Clones to a normal git folder, runs npm install, builds the app and starts it. Set STANZA_DIR first to pick another folder.

3

Updating

When the repo has new commits, a download icon appears in the app with a list of what changed. Click Update; it rebuilds and reopens with your tabs.

Prefer to do it by hand? 
git clone https://github.com/AalishMS/Stanza.git
cd Stanza
npm install
npm start

To use it as a normal app, build it and (on Windows) add shortcuts with npm run package and npm run shortcut. On a Mac, npm run package:mac builds an unsigned Stanza.app for your own machine. Stanza.exe C:\some\folder adds that folder as a project and opens a session in it.

macOS works but isn't tested by the author. If you try it and something breaks, please open an issue.

FAQ

Questions people ask first.

Does Stanza replace Claude Code?

No. Every tab runs the actual claude CLI, so slash commands, permissions and model switching behave exactly as in a shell. Stanza only adds a project sidebar, tabs, split panes, git status and a panel of session details around it.

Is it free? What does it send over the network?

It's free, MIT licensed, with no account and no telemetry. The only network calls are a git fetch of your clone to check for updates, and, for the plan-limit meter, a request to Anthropic's usage endpoint using Claude Code's own login token. The token is read, never written.

Will my existing projects and sessions show up?

Yes. Stanza reads Claude Code's own transcripts under ~/.claude/projects (read-only) and lists them under each project by title. On first launch it also adds the three folders you used Claude Code in most recently.

Does it work on macOS?

It's built Windows first, and every change is written with a Mac path alongside. It works on a Mac, but the author hasn't been able to test it there, so expect the odd rough edge. Reports are welcome.

How do I uninstall it?

Delete the install folder and the shortcuts (or the ~/Applications link on macOS). Your projects and settings live outside the repo, in %APPDATA%\stanza on Windows or ~/Library/Application Support on macOS, so remove those too if you want a clean slate.

Why do some colors look off after switching to the light theme?

Claude Code picks some of its own colors. Run /theme in a session and choose a light theme there as well.
